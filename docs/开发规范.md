## 变更边界

Go 使用 gofmt、pgx 和受版本管理的 SQL。迁移由 `knowledge.Open` 在锁和事务内依序应用。修改共享响应要兼容既有客户端和已存数据，尤其是双集范围、独立分集、已发布 slug 和段落锚点。H5 路由文件驱动生成 `routeTree.gen.ts`。公开正文沿 server loader 返回，交互状态留在对应组件。[迁移入口](../apps/api/internal/knowledge/store.go) · [共享类型](../packages/shared/knowledge.ts)

数据服务拥有业务幂等和发布决定。扩展 Agent 步骤时说明输入、允许的来源、输出、重试标识、终止条件和可追溯记录。将输出按不可信输入核验后再入库；观察模型调用的成功与否不能替代发布凭证。给已发布版本追加新范围时保留旧投影和回跳。[取证校验](../apps/api/internal/knowledge/research.go) · [媒体回执](../apps/api/internal/knowledge/media.go)

## 可执行反馈

在仓库根目录运行。常规检查无需访问计费模型。未提供 `KNOWLEDGE_TEST_DATABASE_URL` 时，部分 PostgreSQL 集成测试会跳过。下面第二条复用本机连接，在专用临时 schema 中建表并清理，需要建 schema 权限。

```sh
npm run check
node_modules/.bin/dotenv -e .env -- sh -c 'export KNOWLEDGE_TEST_DATABASE_URL="$DATABASE_URL"; go -C apps/api test ./... -count=1'
python3 -m json.tool data/episode-plans/naruto-tv-2002.json >/dev/null
docker compose config --quiet
python3 docs/check.py
git diff --check
```

`npm run check` 包含 Web 生产构建、workspace TypeScript 检查、Go vet 和 Go 测试。界面行为另在 375、390、430px 及桌面宽度实点。对照已发布世界 API 与 SSR 源码，验证正文、下一集和 `#passage-*`。自动化示例见[分集集成测试](../apps/api/internal/knowledge/episode_plan_test.go)与[作品阅读路径测试](../apps/api/internal/knowledge/world_test.go)。
