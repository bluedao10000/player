# 读者登录与「我的」

[打开手机交互原型](index.html) · 设计稿，2026-11-20。原型可离线打开，图片取自本次公开定稿，阅读链接进入实际 H5。示例用户、书架、订单与余额用于走查，刷新后恢复访客态。

## 读者什么时候需要账户

从搜索进入《蓦然回首》，读到藤野重新提笔，这条路径全程允许匿名访问。读者希望换设备接着读、同步收藏或查看属于自己的约稿时，再邀请登录。登录完成后回到发起操作的位置，包括作品、集号和段落。首次从底部「我的」进入时，即使还没登录也先展示本机的阅读记录。

| 入口 | 访客 | 已登录读者 |
| --- | --- | --- |
| 章节「加入书架」 | 先保存在本机，提供「登录以同步」，可继续读原段 | 将同一公开章节加入云书架，重复点击保持同一条记录 |
| 底部「我的」 | 本机继续阅读、本机书架、登录入口 | 继续阅读、跨作品书架、我的约稿、可用余额、账户设置 |
| 约稿、余额、订单深链 | 登录并返回原目标。既有访问码读者保留当前入口 | 按服务端绑定的计费账户读取。付费操作仍需单独确认 |

## 登录页

拟使用独立路由 `/login`。手机上方用一幅作品插画和作品名建立阅读上下文，下方是微信与邮箱两种方式；宽屏为左右双栏。返回或取消应回到起点。原型可从登录页直接进入，也可从访客的「余额与明细」唤起，体验按原意图返回。

- **微信**。中国站优先显示已配置的微信入口。桌面展示可过期、可刷新的二维码；手机提供适用于当前浏览环境的授权入口。当前环境只有扫码能力时，在本机优先给出邮箱选项。用户取消时保留阅读位置。
- **邮箱**。输入邮箱 → 获取六位验证码 → 确认登录。验证码 5 分钟有效，输入错误可原地改正，过期可重发，支持更换邮箱。重复发码有冷却，刷新只恢复待验证邮箱与剩余时间。正式页只在服务端启用对应渠道后展示。
- **回到原处**。保存站内路径、查询参数和锚点。例如从《章鱼哔的原罪》第 1 集登录后，回到 `#passage-first-thanks`。服务端只接受本站允许的返回路径。付费入口仅恢复订单或报价页，用户重新确认后再扣款。
- **身份边界**。resume 中国站已经使用微信、可配置的社交登录及邮箱验证码，账户页分开显示身份和账户数据，额度读取失败支持单独重试。本方案沿用这些交互。首版时光读者身份由本项目维护，GitHub 登录暂不列入首发。resume 现用的 `www.codeiy.com/api/auth/callback/wechat` 等回调已转给 `r.codeiy.com`；时光单独登记 `/reader-auth/callback/wechat`。共享 Folio 身份可作为未来独立接入项目。

## 「我的」功能页

保留底部栏的位置，拟将「我的」目标设为 `/me`，`/shelf` 继续作为书架深链。账户信息按需读取，页面正文与操作顺序如下。

| 从上往下 | 展示与操作 | 空态或异常 |
| --- | --- | --- |
| 读者身份 | 游客显示「阅读记录保存在本机」及登录按钮。登录后显示昵称、账户设置和退出 | 会话到期时显示重新登录，保留公开阅读和本机记录 |
| 继续阅读 | 展示作品、章节标题、上次段落及场景图。「接着读」返回已发布的 href 和锚点 | 首次访问不显示虚构进度，直接给「发现作品」入口。旧进度只有百分比时沿用现有恢复方式 |
| 我的书架 | 封面、作品名和章节；最近收藏优先。点「查看全部」可按作品筛选、移除 | 空书架显示「去找故事」。作品若停止公开，保留记录并标示状态 |
| 我的创作 | 「我的约稿」展示待处理或已交付状态，进入订单详情；「余额与明细」分开展示可用、已预留和流水 | 未绑定显示「关联已有预付账户」或开通入口；取数失败显示重试，余额保持未知。服务端确认到账后才更新余额 |
| 账户设置 | 昵称、已验证的登录方式、旧账户关联状态、退出 | 退出撤销会话、清除私有数据缓存；公共内容仍可阅读，下一位登录者看不到前一账户的资料 |

## 接入现有系统

| 能力 | 当前事实 | 实施方案 |
| --- | --- | --- |
| 读者身份 | Gin 已有访问码换计费会话。H5 的计费 Cookie 为 HttpOnly，当前 Path 为 `/reader-api` | Gin 增加 reader、verified identity、可撤销会话；以 provider 与 provider subject 的唯一组合确认身份。H5 私有请求走同源代理。身份会话和旧计费会话明确区分，配套调整公网反代的 Cookie 白名单 |
| 书架与进度 | `/shelf` 读取浏览器中的原创故事 slug，跨作品章节已能记录最近阅读与百分比 | 新记录用作品与内容的稳定身份、已发布 href、段落键和更新时间。旧原创 slug 映射回现有地址。账户第一次登录提示是否并入本机记录，收藏去重；进度取最近一次有效阅读，保留刻意回读。共享设备允许跳过导入 |
| 钱包、约稿 | PostgreSQL 的 billing accounts、orders、entries 已支持预留、结算与流水，现有读者可用访问码登录 `/commissions` | 加 reader 与 billing account 的唯一关联。关联旧账户须同时证明读者身份及访问码持有权，事务内绑定，冲突提示恢复；沿原账本查询订单与余额。登录、导入和绑定重试均不能产生充值或重复订单 |
| 可观察与索引 | 公共路由已有 sitemap，书架和约稿页有独立访问语义 | 登录、我的和私有 API 使用 noindex 或 private/no-store；统计登录发起、成功返回、书架导入和接续阅读。日志中排除验证码、访问码与会话凭据 |

**实施顺序**：先交付访客版「我的」和跨作品本机书架，再接入邮箱验证码、身份会话和跨设备同步，随后在独立回调就绪后增加微信和旧预付账户绑定。每一步都保留原有阅读和访问码入口。

**上线验收**：访客从搜索直达原段；登录取消仍能阅读；验证码过期可重发；同一读者换设备能回到最近章节；两次导入不会重复收藏；绑定前后的余额、订单及流水相同；另一个读者无法读取该账户订单；退出后浏览器后退不显示私有金额。

项目入口见[书架与收藏](../../apps/web/src/features/post/storage.tsx)、[阅读进度](../../apps/web/src/features/post/progress.tsx)、[约稿与钱包](../../apps/web/src/features/billing/commissions.tsx)、[计费会话代理](../../apps/web/src/features/billing/proxy.server.ts)及[公网回调分流](../../deploy/player-ingress.conf)。resume 对照位置为其仓库中的 `src/components/LoginMethods.tsx`、`EmailOtpLogin.tsx`、`AccountDetails.tsx` 和 `src/server/auth.ts`。
