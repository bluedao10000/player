# 功能地图

[待开发功能 PNG](diagrams/backlog.png) · [矢量图](diagrams/backlog.svg) · [可编辑图源](diagrams/backlog.mmd)。图中状态记录 2026-11-19 的基线，最新状态见下表。

路径按验收动作排列。知识库读端点以 `/api/v1/knowledge` 为前缀，管理端点另用 `/api/v1/admin/knowledge`。

| 任务 / 页面 | 数据与实现入口 | 当前边界 |
| --- | --- | --- |
| 首页 `/`、作品目录 `/works`、角色图鉴 `/characters`、故事书库 `/stories` | [发现页与目录](../apps/web/src/features/worlds/discover-pages.tsx) → [发布目录查询](../apps/api/internal/knowledge/world_api.go) | 首页跨作品选取封面、人物、章节和场景。三个目录支持搜索，人物和章节可按作品筛选，链接沿用发布记录中的地址 |
| `/knowledge` 搜索、`/knowledge/$id` 查作品 | [查询前端](../apps/web/src/features/knowledge-api.ts)、[目录 API](../apps/api/internal/knowledge/api.go) | 支持名称/别名和 UUID；只有已建世界的作品有阅读入口 |
| `/work/$work` 读人物、章节、场景 | [路由](../apps/web/src/routes)、[世界页面](../apps/web/src/features/worlds/pages.tsx)、[世界 API](../apps/api/internal/knowledge/world_api.go) | H5 子路径为 character、chapter、scene；Gin 为 characters、chapters、scenes。返回链接含稳定段落锚点 |
| `/character/mio`、`/story/$slug`、`/play/$slug` | [原创角色与故事](../apps/web/src/features/post)、[分支控制](../apps/web/src/features/post/roleplay-controls.tsx) | 移动端预设行动、本地存档与收藏；自由输入和服务端互动会话待开发 |
| `/workbench` 用一句话修订章节、场景、人物介绍与世界观 | [工作台](../apps/web/src/features/workbench/editor-desk.tsx)、[数据服务调度](../apps/api/internal/knowledge/editor_worker.go)、[审稿发布](../apps/api/internal/knowledge/editor.go) | 《火影忍者》2002 TV 第 1 集与潮汐邮局《海风里的夜班邮差》。可选章节与场景，或本章出场人物与作品世界观。私有手机预览、按任务批准、冲突保护，旧链接和段落保持稳定 |
| `/workbench?view=data` 看同步、质检、取证与验收 | [工作台 feed](../apps/web/src/features/workbench/feed.ts)、[范围报告](../apps/web/src/features/workbench/scope-report.tsx) | 轮询 Gin 读接口；查看每集五维缺项及上一轮退回原因 |
| 比较场景图和角色肖像 | [试稿画廊](../apps/web/src/features/workbench/media-gallery.tsx)、[媒体调度](../apps/api/internal/knowledge/media.go) | 原图、手机预览、自动复核与返工均可追溯。候选文件和读者图片使用不同路由 |
| 定时补档案、登记选题、推进范围 | [数据服务入口](../apps/api/cmd/knowledge-sync/main.go)、[配置说明](../data/episode-plans/README.md) | 目录同步与高成本选题独立。配置式取证当前支持已有 Naruto 资料页面结构 |
| 来源冲突判同与治理 | [治理路由](../apps/api/internal/knowledge/curation.go)、[AI 辅助评估](../apps/api/internal/knowledge/match_ai.go) | 规则归并、候选评估、审计与重算；部分管理员操作在 Gin 请求内执行 |
| 查各类模型消耗 | [回执管理 API](../apps/api/internal/knowledge/usage.go)、[口径与计费设计](模型用量与计费.md) | 已可按用途、账户与模型查询 token，追踪单次调用及缺失、冲突回执 |
| 访客「我的」 `/me` 与原书架 `/shelf` | [访客页](../apps/web/src/features/reader/guest.tsx)、[本机收藏](../apps/web/src/features/reader/bookmarks.ts)、[章节进度](../apps/web/src/features/post/progress.tsx) | 本地 H5 已接入。可跨作品收藏章节、按作品筛选及移除；新进度回到正文段落，旧百分比及原创收藏可继续使用。 |
| 微信扫码与读者等级 | [读者身份](../apps/api/internal/reader/wechat.go)、[会员权益](../apps/api/internal/reader/plans.go)、[接入与验收](读者账户/设计.md#微信登录与读者会员) | 微信网站扫码登录与邮箱绑定；Free、Plus、Pro 周期积分、支付宝会员订单和核验到账。 |
| 邮箱登录、跨设备接续阅读 | [登录与导入](../apps/web/src/features/reader/login.tsx)、[读者会话与云书架](../apps/api/internal/reader)、[集成测试](../apps/api/internal/knowledge/reader_test.go) | 本地 H5 已接入。首次登录选择合并或跳过，其他设备用同一邮箱接续到已保存段落。 |
| 我的书架 → 私人约稿 `/commissions` | [H5 购买页](../apps/web/src/features/billing/commissions.tsx)、[自动履约](../apps/api/cmd/media/orders.go)、[账户与订单 API](../apps/api/internal/billing/api.go) | 预付账户可确认最高价、查看余额、排队、取消、取图和查流水。管理员开通账户。CNY 账户可通过支付宝网页充值，回调验签入账；真实商户联调待配置 |
| 核对供应商账单 | [对账查询](../apps/api/internal/billing/reconciliation.sql)、[验收与口径](模型用量与计费.md) | 管理 API 导入供应商日汇总，核对两侧差额、回执与同币种毛利。供应商自动拉单待接入 |
| 作品页搜索发现 | [页面元信息](../apps/web/src/features/seo/world.ts)、[自动 sitemap](../apps/web/src/routes/sitemap%5B.%5Dxml.ts) | 作品、章节、角色和场景页已有 canonical 和 SSR JSON-LD。新公布的作品页按首页作品列表进入 sitemap。工作台和预览页在公网返回 404。见[公网验收](架构实现核验.md#2026-11-20-公网发布与搜索验收) |
| iOS 读者端 | [工程与验收](../apps/ios/README.md)、[Apple 验单](../apps/api/internal/billing/storekit.go)、[约稿充值](../apps/api/internal/billing/store_wallet.go) | SwiftUI 阅读、账户、书架、会员与充值已编写。微信移动应用配置、App Store 三个商品配置与真机支付验收待完成。 |

新增能力时，在相应行补上真实入口、数据所有者与可观察结果。页面效果由浏览器验收，业务发布状态由范围记录核实。[核验方法](架构实现核验.md)
