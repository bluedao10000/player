路径按验收动作排列。知识库读端点以 `/api/v1/knowledge` 为前缀，管理端点另用 `/api/v1/admin/knowledge`。

| 任务 / 页面 | 数据与实现入口 | 当前边界 |
| --- | --- | --- |
| 首页 `/`、作品目录 `/works`、角色图鉴 `/characters`、故事书库 `/stories` | [发现页与目录](../apps/web/src/features/worlds/discover-pages.tsx) → [发布目录查询](../apps/api/internal/handler/knowledge/world_api.go) | 首页跨作品选取封面、人物、章节和场景。三个目录支持搜索，人物和章节可按作品筛选，链接沿用发布记录中的地址 |
| `/knowledge` 搜索、`/knowledge/$id` 查作品 | [查询前端](../apps/web/src/features/knowledge-api.ts)、[目录 API](../apps/api/internal/handler/knowledge/api.go) | 支持名称/别名和 UUID；只有已建世界的作品有阅读入口 |
| `/work/$work` 读人物、章节、场景 | [路由](../apps/web/src/routes)、[世界页面](../apps/web/src/features/worlds/pages.tsx)、[世界 API](../apps/api/internal/handler/knowledge/world_api.go) | H5 子路径为 character、chapter、scene；Gin 为 characters、chapters、scenes。返回链接含稳定段落锚点 |
| `/character/mio`、`/story/$slug`、`/play/$slug` | [原创角色与故事](../apps/web/src/features/post)、[分支控制](../apps/web/src/features/post/roleplay-controls.tsx) | 移动端预设行动、本地存档与收藏；自由输入和服务端互动会话待开发 |
| `/workbench` 运营总览 | [Overview 页面与 feed](../apps/web/src/features/workbench/dashboard/overview.tsx)、[聚合接口](../apps/api/internal/handler/knowledge/usage.go) | 服务端读取作品、知识资产、执行、队列、心跳和今日计数；按口径更新时间展示。工作台仍限本机并要求编辑会话 |
| `/workbench/operations` 运营拓扑 | [工作流拓扑](../apps/web/src/features/workbench/workflow/workflow-canvas.tsx)、[运行日志](../apps/web/src/features/workbench/terminal/live-terminal.tsx) | 复用现有拓扑与日志；节点计数口径留到 Phase 3 |
| `/workbench/knowledge` 知识资产 | [作品库存、范围验收和媒体图库](../apps/web/src/features/workbench) | 复用 `WorldInventory`、`ScopeReport`、`MediaGallery`；候选参数可直达图片详情 |
| `/workbench/projects` 项目 | [分集制作计划](../apps/web/src/features/workbench/production-plans.tsx)、[补集与发布记录](../apps/web/src/features/workbench/dashboard/operations.tsx)、[制作报表](../apps/web/src/features/workbench/production-report.tsx) | 计划从审稿工作台拆出；沿用原编辑计划接口、补集准入与正式站发布保护 |
| `/workbench/analytics` 运营分析 | [制作报表与备份报表](../apps/web/src/features/workbench/production-report.tsx)、[备份状态](../apps/web/src/features/workbench/backup-report.tsx) | 先展示制作回执和备份；趋势分析在 Phase 4 |
| `/workbench/exceptions` 异常与决策 | [完整关注列表](../apps/api/internal/repository/queries/ops/ops.queries)、[编辑审稿](../apps/web/src/features/workbench/editor-desk.tsx) | 查看全部离线/持续出错进程、阻塞和待人工项、近 24 小时失败执行；编辑审稿任务链接会预选任务 |
| `/workbench/assistant` AI 助手 | [对话界面](../apps/web/src/features/workbench/chat.tsx)、[计划确认](../apps/api/internal/handler/knowledge/chat.go) | 本地对话支持查询制作进度和提出结构化修改。确认后写入 revision 和审计，保留会话与操作记录 |
| `/workbench/me` 我的 | [工作台账户](../apps/web/src/features/workbench/editor-desk.tsx) | 账户与密码管理入口固定在侧栏底部 |
| 工作台旧 `?view=`、`?section=` 链接 | [重定向映射与测试](../apps/web/src/features/workbench/legacy-links.ts)、[Phase 1 文档](运营中心-Phase1.md) | 审稿、计划、日志、图片候选的旧深链转到新子路由并保留详情参数 |
| 比较场景图和角色肖像 | [试稿画廊](../apps/web/src/features/workbench/media-gallery.tsx)、[媒体调度](../apps/api/internal/service/knowledge/media.go) | 原图、手机预览、自动复核与返工均可追溯。候选文件和读者图片使用不同路由 |
| 管理独立图片库 | [资产 API](../apps/image/openapi.yaml)、[部署](../apps/image/README.md) | 独立 Compose 已支持资产、转换和 AI 任务。公开读图仍使用火影灰度清单；R2 迁移待实施 |
| 定时补档案、登记选题、推进范围 | [数据服务入口](../apps/sync/cmd/sync/main.go)、[配置说明](知识库构建流程.md) | 目录同步与高成本选题独立。同版来源模板可复用时，sync 盘点缺口，调用 Pi 生成配置，校验后登记并执行。没有兼容模板的集数仍需补来源规则 |
| 来源冲突判同与治理 | [治理路由](../apps/api/internal/service/knowledge/curation.go)、[AI 辅助评估](../apps/api/internal/handler/knowledge/match_ai.go) | 规则归并、候选评估、审计与重算；部分管理员操作在 Gin 请求内执行 |
| 查各类模型消耗 | [回执管理 API](../apps/api/internal/handler/knowledge/usage.go)、[口径与计费设计](模型用量与计费.md) | 已可按用途、账户与模型查询 token，追踪单次调用及缺失、冲突回执 |
| 访客「我的」 `/me` 与原书架 `/shelf` | [访客页](../apps/web/src/features/reader/guest.tsx)、[本机收藏](../apps/web/src/features/reader/bookmarks.ts)、[章节进度](../apps/web/src/features/post/progress.tsx) | 本地 H5 已接入。可跨作品收藏章节、按作品筛选及移除；新进度回到正文段落，旧百分比及原创收藏可继续使用。 |
| 微信扫码与读者等级 | [读者身份](../apps/api/internal/handler/reader/wechat.go)、[会员权益](../apps/api/internal/handler/reader/plans.go)、[接入与验收](读者账户/设计.md#微信登录与读者会员) | 微信网站扫码登录与邮箱绑定；Free、Plus、Pro 周期积分、支付宝会员订单和核验到账。 |
| 邮箱登录、跨设备接续阅读 | [登录与导入](../apps/web/src/features/reader/login.tsx)、[读者会话与云书架](../apps/api/internal/handler/reader)、[集成测试](../apps/api/internal/handler/knowledge/reader_test.go) | 本地 H5 已接入。首次登录选择合并或跳过，其他设备用同一邮箱接续到已保存段落。 |
| `/workbench/analytics` → 广州制作库备份 | [备份采集器](../apps/sync/cmd/backup-report/main.go)、[工作台面板](../apps/web/src/features/workbench/backup-report.tsx) | 展示最近一次通过恢复校验的备份与最近 30 次执行。可核对大小、耗时、逐表校验、失败原因与采集心跳。 |
| 核对供应商账单 | [对账查询](../apps/api/internal/repository/queries/billing/queries.queries)、[验收与口径](模型用量与计费.md) | 管理 API 导入供应商日汇总，核对两侧差额、回执与同币种毛利。供应商自动拉单待接入 |
| 作品页搜索发现 | [页面元信息](../apps/web/src/features/seo/world.ts)、[自动 sitemap](../apps/web/src/routes/sitemap%5B.%5Dxml.ts) | 作品、章节、角色和场景页已有 canonical 和 SSR JSON-LD。新公布的作品页按首页作品列表进入 sitemap。工作台和预览页在公网返回 404。见[公网验收](架构实现核验.md#2026-11-20-公网发布与搜索验收) |
| iOS 读者端 | [工程与验收](../apps/ios/README.md)、[Apple 验单](../apps/api/internal/service/billing/storekit.go) | SwiftUI 阅读、账户、书架与会员购买已编写。微信移动应用配置、App Store 两个会员商品配置与真机支付验收待完成。 |

新增能力时，在相应行补上真实入口、数据所有者与可观察结果。页面效果由浏览器验收，业务发布状态由范围记录核实。[核验方法](架构实现核验.md)
