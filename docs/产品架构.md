# 产品架构

首页的产品单位是「一部作品的世界」。搜索进来的读者可以先读人物或章节，再沿出场关系和场景链接探索。私人互动由具体故事承接。公开内容能长期访问，运营端可以解释每一段和每一张图的来历。[产品图](diagrams/product.svg) · [功能地图](功能地图.md)

| 面向谁 | 已有体验 | 成功信号 |
| --- | --- | --- |
| 新读者 | 从首页作品栏或知识库搜索找到特定版本。作品页展示人物、章节、场景与已完成范围 | 《火影忍者》2002 TV 与同名续作有独立作品身份 |
| 回访读者 | 人物列出出场章节，场景保留回到原段的链接。潮汐邮局支持本机书架和预设剧情选择 | 新增一集后，旧书签、段落回跳和选图仍有效 |
| 内容运营 | 用配置确定作品版本、选题集号、取证问题和美术参考。数据工作台显示进度、退回原因、候选原图和手机裁切 | 能判断某集卡在来源、导读、肖像还是场景图，并查到依据 |
| 审稿人 | 在统一工作台选章节、用一句话提意见，对照原稿、来源和 H5 手机预览，整项通过或退回 | 发布同一任务的正文和场景后，旧书签仍跳回同一段 |
| 数据维护者 | 查看来源版本、冲突候选和质量问题，按授权执行带审计的治理操作 | 能从 canonical 作品追查到原始记录、版本及修正原因 |

## 一部作品的三个尺度

**发行状态**来自作品目录，表达原作播出进度和总集数。**可读范围**来自已发布章节和范围验收。**本集完整度**按人物、剧情、世界观、时间线、图片五个维度保存证据和缺项。原作全 220 集的《火影忍者》可以只完成前五集；搜索命中的其他作品也可以只有基础档案。[状态查询](../apps/api/internal/knowledge/api.go) · [范围发布](../apps/api/internal/knowledge/world_api.go)

## 三种样板

- **潮汐邮局**用于原创阅读和互动。原创作品图谱从仓库资料入库；首页港口栏目、立绘与预设分支仍有前端策划内容。[原创资料](../apps/api/internal/knowledge/worlddata) · [前端目录](../apps/web/src/features/post/catalog.ts)
- **《星际牛仔》1998 TV**用于验证历史定稿和增量。前两集共用一个范围，第 3 集有独立定稿。新增能力需兼容两种范围。[增量验收](../apps/api/internal/knowledge/episode_three.go)
- **《火影忍者》2002 TV**用于按集配置，多个章节复用人物肖像。首页作品入口展示知识库作品，公开范围随连续通过的集数推进。[分集清单](../data/episode-plans/naruto-tv-2002.json)

移动 H5 与 SSR 已可运行。深度自由角色扮演、账号同步、跨作品的人物与世界观编辑、完整 SEO/GEO 工具链及 iOS 包装仍属于后续产品能力。[实现核验](架构实现核验.md)
