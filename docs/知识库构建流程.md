# 从已清洗作品到分集定稿

一次选题锁定作品身份、发行版本和集数范围。以《火影忍者》第 5 集为例，正式章节需要解释卡卡西为何改变结论，并让读者从「分享午饭」回到有依据的原段。[业务流程图](diagrams/business.mmd) · [目标采集架构](diagrams/target-collection.html) · [配置示例](../apps/sync/episode-plan.example.json)

| 阶段 | 谁执行、写到哪里 | 推进条件与失败信号 |
| --- | --- | --- |
| 目录清洗 | Go 将上游记录归并到 PostgreSQL canonical 目录 | 可靠版本、来源标识与年份可核对。普通作品可停在这一阶段 |
| 选题登记 | sync 从已确认计划生成兼容来源的分集配置，也可由管理命令接收分集 JSON，登记 `episode_plans`、`research_topics` 和美术任务设定 | 分集配置绑定同一 TV 版的 provider ID、集号、slug、来源、人物与场景。配置错误见 sync 日志 |
| 联网取证 | Pi 工具读取本集官方资料和独立分集资料；Go 保存 `research_runs.documents` 与 `research_events` | 标题、集号、快照摘要、可定位句子须匹配。失败保留 run、阶段和原因 |
| 写作与校对 | Pi 按顺序组织动机、转折和因果。Go 从快照解析引用，将段落与出处存入 claims | 只有通过结构与引用检查才进入 ready；来源索引保存在取证记录 |
| 出图与验图 | Go 派发候选，Pi 核对参考图摘要，生成原图与手机裁切，调用视觉模型。Go 更新 `media_candidates` 和 `media_steps` | 配置式流程每集三张场景候选，跨集复用肖像。缺陷可触发二次复核、重裁或重绘。保留终止原因与各轮文件 |
| 范围验收 | Go 将五维证据与缺项写入 `scope_acceptances`，以 `scope_heads` 指向最新检查和通过记录 | 有缺项时显示具体维度。配置式选题可将正文缺项退回提升 policy，保留旧稿和退回记录 |
| 对读者发布 | 冻结正文、章段锚点、插图及摘要；Gin 从公开视图返回连续通过的范围 | 后集先通过时等待前置集。H5 的已完成范围可从验收记录与返回链接复查 |

## 五维如何落到一集

| 维度 | 检查什么 |
| --- | --- |
| 人物 | 配置中指定人物能在对应、有来源的正文段落找到，角色页可以列出出场集 |
| 剧情 | 段落覆盖动机、转折和因果，每项引用能定位到同集快照 |
| 世界观 | 该集依赖的设定词出现在选定的有据段落，例如火影、铃铛或同伴 |
| 时间线 | 各剧情节点依次命中分集资料中的事件句子 |
| 图片 | 所需肖像有验图记录和文件；场景候选结束比选后，检查入选原图、裁切、尺寸、摘要及通过回执 |

这些自动门槛衡量当前配置的范围。角色名、设定词和句子定位包含字面匹配条件，来源改版或译名改变可能造成退回。读者页展示自然剧情；数据库保存证据、各轮回执和缺项。[范围检查](../apps/api/internal/service/knowledge/episode_plan.go) · [图片与定稿凭证](../apps/api/internal/service/knowledge/acceptance.go)

## 云端自动补集

按作品版本登记自动制作范围。文本调度器优先选择处于盘点缺口、有已验证配置、且预算仍有余量的集。登记一集与开始付费制作各有自己的时间。采集、写作、出图分别使用共享库中的租约、研究运行和候选编号恢复。入选图、已发布版本与前文章段锚点保留。数据库保存准入、采集失败、模型回执和逐维缺项。[制作配置与预算](../apps/sync/episode-plan.example.json) · [两端运行手册](../apps/sync/ops/production/README.md)

## 扩展与回归

已有来源结构增加一集，可以单独登记该集与所需人物。单机目录导入模式约每 45 秒读取配置；相同清单跳过，已登记项有修改保护。新的上游页面结构需要实现取证适配并验证实际文档格式。《星际牛仔》的历史双集及第 3 集仍有专用取证和验收逻辑。回归时要覆盖配置式单集及历史范围。[配置字段](../apps/sync/episode-plan.example.json) · [取证适配](../apps/agent/src/episode-plan.ts) · [历史范围](../apps/api/internal/service/knowledge/episode_three.go) · [追加配置测试](../apps/api/internal/service/knowledge/episode_plan_test.go)

## 从 sync 运行与核对进度

为已有作品登记分集时，把本集来源、段落定位、角色、场景与预算填入私有计划，通过标准输入交给 sync 项目的管理命令。相同计划可以重复登记；已锁定的集号、路由与来源配置有冲突时会拒绝写入。

```sh
go -C apps/sync run ./cmd/knowledge episode-register < "$PLAN_FILE"
```

运行环境需要配置制作库连接。公开模板只描述字段，使用前应替换示例来源和图片摘要。登记时通过 `automation.first/last` 限定范围，用 `maxEpisodes`、`tokenBudget` 和 `reserveTokens` 控制准入，按集设置 `publishToReader` 才会自动投递正式站。

盘点程序按播出目录和公开章节计算缺口。登记制作范围后，sync 读取已登记的同版本来源模板。对于使用官方合集页和维基分集指南的模板，Pi 从两个页面核对目标集号、标题和原文，再按快照生成分集配置。Go 校验出处顺序、人物复用、路由和参考图片摘要，在一个事务中登记分集、来源快照和制作请求。配置生成用量计入制作计划，失败原因和重试回执保存在制作记录。缺少兼容来源模板的集数仍走配置文件登记。

自动生成配置默认供本地验收。完成五维检查后显示「本地验收通过」。正式发布由现有发布流程读取明确开启投递的配置。

### 生成和复用采集规则

对缺少模板的分集，先提供 2–5 条同版本样本。每条样本含用分集目录核对过的 `number`、`title`、官方 `official` URL 和独立回顾 `guide` URL。续作的页面集号与本站集号不一致时，样本再加 `sourceNumber`（页面上的通算集号）；验证回执按来源集号留证，登记后的分集配置沿用该偏移。用 `episode-source-cli.ts` 提交第一集的页面结构给 OpenAI，提取器随后用所有样本验证规则。规则只含 JSON 字段或 CSS 选择器。验证会核对分集身份、错集号与错标题反例、跨集正文差异和转载重合度，并输出规则和页面摘要。给命令传入现有验证结果时，程序直接复用规则和重新验证。

```sh
node --env-file=.env apps/agent/src/episode-source-cli.ts "$CASES" "$PRIVATE_STATE" > "$VERIFIED_RULE"
go -C apps/sync run ./cmd/knowledge episode-source-rule-attach "$WORLD" < "$VERIFIED_RULE"
```

登记命令把来源和验证结果绑定到队列中的单集任务。分批调度仍按现有额度领取。制作器重新抓取两份来源并执行绑定的规则，来源通过校验后才生成制作配置。旧版维基分集路径继续通过原有入口执行。样本 URL 采用页面的最终地址。

### 旧工作台的历史实跑记录

《星际牛仔》1998 TV 版第 10 集《木卫三挽歌》使用工作台对话提出范围变更。确认前起止集仍为第 9 集，确认后才切换到第 10 集。sync 根据盘点缺口生成并登记双来源配置，配置生成耗时约 30 秒，消耗 1,775 token。

首轮场景配置选择了与剧情人物不符的参考肖像，已暂停任务并修订场景参考和人物段落，再通过对话确认续跑。自动生成配置补充了人物出场原文和参考图指纹校验。媒体在文本四维通过后才领取新任务，避免文本和出图同时占用同一计划的预留额度。实跑过程保留配置、验收退回、用量和重试回执。

三张候选均通过自动验图，五维验收无缺项，入选图已在本地 H5 展示。整项本地计划耗时约 9 分 25 秒，使用 46,778 / 60,000 token。H5 390 像素场景回跳、章节 SSR 锚点和 iOS 读取接口均已校验。前 9 集正文、链接、段落锚点及入选图片摘要与基线一致。该集没有正式站发布记录。
