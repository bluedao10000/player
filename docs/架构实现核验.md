# 架构实现核验 · 2026-11-18

本记录对应作品世界样板接入之前的图集。新版产品架构和知识库流程的状态依据见[交互图集](architecture.html)和[样板实况](作品世界样板/知识库清洗/流程说明.html)。

当时逐项检查了交互图集的 25 个「已实现」节点（产品 4 个、业务 12 个、技术 9 个），以及这些节点之间的实线连接。相同能力在三张图中的证据合并列在下表。部署图描述双云目标，本次实际运行环境为本地 Docker Compose、TanStack Start 与独立 Pi 进程。

| 已实现的节点与路径 | 核验方式与结果 |
| --- | --- |
| 公开阅读 H5、角色和故事 | 关闭 JavaScript 后访问首页、角色页、故事列表、故事详情，均返回 HTTP 200 并有可读标题。SSR 知识搜索结果可沿链接进入 UUID 详情页。 |
| 预设分支、本机进度与收藏 | 浏览器点击收藏后，书架可打开对应故事。在试玩中选择第一种行动，刷新后仍显示原选择；重选第二种行动得到不同结果。 |
| 原创内容与私人图片试稿 | 核对九张既有参考图试稿，所有记录的参考图摘要均与当前阿澪立绘一致，九个输出 SHA-256 各异并匹配实际 PNG。本次重跑 CLI 的参考图上传、尺寸及坏图测试，未重新请求付费出图。 |
| 定时调度、到期探测与跳过 | 本机 Compose 的 sync 进程独立运行。数据库中两源都有成功导入及跳过记录。隔离测试用两种上游格式的 HTTP fixture 验证同版本不重复下载、到期检查及同源并发锁。 |
| 下载、校验、清洗、匹配、首次入库和持续更新 | 在 PostgreSQL 独立测试 schema 从空库运行两源导入，验证暂存、跨源归并、候选保留、增改与来源撤回。已有知识库可查询 39,033 部活动作品。 |
| 失败保护、档案和事务边界 | 注入错误摘要、截断响应、部分暂存后解析失败及作品约束失败，检查原版本仍可查询、暂存清理。历史快照重建保留人工覆盖，损坏归档被拒绝。 |
| 定时质检、评分、记录与观测 API | 真实库有 13 条启用规则；最近成功报告覆盖 39,033 部，均分 66.38。集成测试验证重复调度只产生一条成功记录，到期后产生第二条，并验证修复后问题关闭。 |
| Gin 查询、治理与鉴权 | 未带凭据的管理请求返回 401。隔离测试覆盖候选详情、字段覆盖与撤销、身份审核及审计查询。Jev 适配器使用模拟模型响应验证协议及失败分支。 |
| PostgreSQL → Gin → H5 / Pi | 浏览器完成真实作品搜索和详情读取；分别执行 Pi 扩展注册的搜索和详情工具，按搜索返回的 UUID 获取作品，并读到两个来源。 |
| Pi Durable 运行时 | 用临时 SQLite 启动 Agent、检查健康、关闭，再用同一数据库重新启动。此次验证范围为启动、重开存储、运行 resume 和只读知识工具。 |
| 数据工作台 | 浏览器检查 1440、375、390、430px 视口，验证拓扑切换、节点详情、日志筛选和暂停刷新。工作台读取 Gin 的同步和质检记录，图片视图标为规划。 |

图片任务自动调度、Pi 多轮图片优化、Jev 图片疑点复核、资产自动发布、服务端多轮角色扮演和双云部署仍按目标能力标注。本次没有测量 Jev 在线判同准确率、执行新的云部署或模拟生产负载。

复验入口包括仓库根目录的 `npm run check`，以及在 apps/api 下设置指向测试 PostgreSQL 的 `KNOWLEDGE_TEST_DATABASE_URL` 后运行 `go test -count=1 -v ./...`。数据库生命周期测试创建并清理自己的 schema。图集的 SVG 节点、源码链接、窄屏交互和四份 Mermaid 图源另经浏览器验证。
