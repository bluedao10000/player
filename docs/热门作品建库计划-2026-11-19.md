## 根目录 .env 采购与填写清单

以下是与本次生产有关的变量名。模型示例取自项目模板或供应商公开资料；可用模型及权限以账户为准。本次未验证任何私密凭据、未投递选题任务。

| 用途 | 变量名 | 建议设置 |
| --- | --- | --- |
| 知识库取证、写作 | `CONTENT_AI_API_KEY`、`CONTENT_AI_BASE_URL`、`CONTENT_AI_MODEL`、`CONTENT_AI_PROTOCOL`、`CONTENT_AI_ACCOUNT` | 用已有 DeepSeek Key。示例端点 `https://api.deepseek.com`、模型 `deepseek-flash`、协议 `chat-completions`、账户别名 `deepseek-studio`。试点验证 Pi 工具调用及流式 usage |
| 场景、肖像生成与编辑 | `MEDIA_AI_API_KEY`、`MEDIA_AI_BASE_URL`、`MEDIA_AI_MODEL`、`MEDIA_AI_ACCOUNT` | 用有图像生成和编辑权限的 OpenAI Key。项目默认 `https://api.openai.com/v1`、`gpt-image-2` |
| 图片初审与复审 | `VISION_AI_API_KEY`、`VISION_AI_BASE_URL`、`VISION_AI_MODEL`、`VISION_AI_SECOND_MODEL`、`VISION_AI_ACCOUNT` | 用支持图片输入和 Responses 的 OpenAI Key。初审、复审默认分别为 `gpt-4.1-mini`、`gpt-4.1`。与出图共用供应商计费账户时可复用具有两种权限的 Key，并用相同账户别名 |
| Jev 判同，可选 | `MATCH_AI_PROVIDER`、`TYPESAFE_API_KEY`、`TYPESAFE_BASE_URL`、`TYPESAFE_MODEL`、`TYPESAFE_ACCOUNT` | 选择 `typesafe`；使用 TypeSafe 提供的 Key。默认 `https://api.typesafe.ai/v1`、`jev-latest`。三家现有模型服务的 Key 不能直接充当 Jev 凭据 |
